# Laboratorios de Análisis Numérico (UTN - EAB / ISI). Año 2026.

Este repositorio centraliza las entregas de los laboratorios de programación de la materia. El objetivo es que les estudiantes utilicen herramientas profesionales de versionado y colaboración.

## Estructura de carpetas
Tenés que realizar las entregas dentro de la carpeta `/entregas` siguiendo este formato:

`entregas/apellido_nombre/lab_X_titulo.ipynb`,

donde _X_ es el número del laboratorio y _apellido_, _nombre_ y _titulo_ significan lo que creés que significan.

## Flujo de entrega (_pull request_)
Para entregar un laboratorio, tenés que:
1. Realizar un _**fork**_ de este repositorio.
2. Trabajar en tu propia copia.
3. Subir el archivo de _Jupyter Notebook_ a tu carpeta personal.
4. Abrir un _**pull request (PR)**_ hacia la rama `main` de este repositorio original.

## Proceso de revisión y corrección (iterativo)
Una vez enviado el PR, el docente revisará el código. Generalmente acá empieza un proceso iterativo:
- **Comentarios:** el docente puede agregar comentarios en líneas específicas de tu código solicitando aclaraciones o correcciones. Vas a recibir una notificación si esto ocurre.
- **Corrección:** si el PR no es aprobado inicialmente, **no tenés que abrir un nuevo PR**. Simplemente hacé los cambios necesarios en tu repositorio (_fork_) y cuando lo tengas listo hacé un nuevo `push`. El PR abierto se actualizará automáticamente con tus correcciones y el docente será notificad@.
- **Aprobación:** una vez que el trabajo cumpla con los objetivos, el docente realizará el *merge*, incorporando tu entrega oficialmente al repositorio de la cátedra. Eso significa que el laboratorio está aprobado :-D .
